# devops-docs

Практическая работа № 9. Pylint, MkDocs, GitHub Actions и GitHub Pages.

- Исходники документации — `docs/`.
- Конфигурация MkDocs — `mkdocs.yml`.
- Проверка — `.github/workflows/quality.yml`.
- Публикация — `.github/workflows/pages.yml`.

Каталог `site/` создаётся при сборке и исключён из Git.
