# Эксплуатация

## Штатная публикация

1. Убедитесь, что проверка `pylint` в Pull Request успешна.
2. Выполните слияние в `main`.
3. Откройте Actions → Publish documentation.
4. Дождитесь успеха заданий `build` и `deploy`.
5. Откройте URL окружения `github-pages` и проверьте главную страницу.

## Ручной перезапуск

Для повторной публикации используйте Actions → Publish documentation → Run workflow.

## Диагностика

Определите, на каком этапе произошёл сбой. Затем проверьте журнал соответствующего шага и внесите исправление.

## Восстановление

Перед восстановлением изучите [инструкцию по аварийному восстановлению](recovery.md).
