# Журнал типовых инцидентов

| Инцидент | Наблюдаемый признак | Где искать причину |
|---|---|---|
| Неиспользуемая переменная | Ошибка `pylint` в PR | Журнал шага Static analysis |
| Недостаточные права | Сборка прошла, публикация остановилась | Журнал deploy и блок `permissions` |
| Битая ссылка | `mkdocs build --strict` завершился с ошибкой | Журнал шага Build documentation |
| Старая версия сайта | Сборка зелёная, содержимое прежнее | URL окружения, время публикации, кэш |

## Разбор

Укажите симптом, доказательство из журнала, причину, исправление и результат повторной проверки.
